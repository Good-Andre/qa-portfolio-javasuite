# ✅ Mobile Testing Checklist

## Функциональные проверки

- [ ] Вход/регистрация: корректная валидация, сообщения об ошибках, восстановление пароля.
- [ ] Основные сценарии: ключевые действия пользователя (например, «собрать пазл», «купить предмет», «отправить сообщение»).
- [ ] Граничные значения: пустые поля, спецсимволы, очень длинные строки.
- [ ] Синхронизация данных: повторные запросы, идемпотентность, обработка ошибок сети.

## UI/UX и адаптивность

- [ ] Адаптация под портретную и альбомную ориентацию.
- [ ] Корректное отображение на планшетах и нестандартных экранах.
- [ ] Читаемость текста при увеличении системного шрифта (до 150–200%).
- [ ] Соответствие гайдлайнам (Material Design / Human Interface Guidelines).

## Сенсорные взаимодействия

- [ ] Одиночные тапы: открытие, выбор, подтверждение.
- [ ] Свайпы: навигация, удаление, раскрытие меню.
- [ ] Пинч/зум: масштабирование изображений, карт, пазлов.
- [ ] Мультитач: одновременные нажатия, жесты.
- [ ] Длительное нажатие: контекстное меню, перетаскивание.

## Жизненный цикл

- [ ] Запуск из холодного состояния.
- [ ] Сворачивание и восстановление без потери состояния.
- [ ] Kill процесса ОС и восстановление (частичное/полное).
- [ ] Push‑уведомления: получение, переход по уведомлению, обработка при закрытом приложении.

## Сеть и офлайн

- [ ] Работа в офлайн‑режиме: кэширование, офлайн‑действия, очередь запросов.
- [ ] Переключение между Wi‑Fi и мобильным интернетом.
- [ ] Слабый сигнал: таймауты, повторные попытки, понятные сообщения.

## Производительность

- [ ] Время запуска: холодный/горячий старт.
- [ ] FPS при активных анимациях и скролле.
- [ ] Потребление памяти: утечки, рост при длительных сессиях.
- [ ] Энергопотребление: фоновая активность, частые запросы.

## Доступность

- [ ] Поддержка TalkBack (Android) и VoiceOver (iOS).
- [ ] Семантика элементов: кнопки, поля ввода, заголовки.
- [ ] Контрастность: соответствие WCAG AA.
- [ ] Управление с клавиатуры (если применимо).

## Безопасность

- [ ] Хранение токенов: безопасное хранилище (SecureStorage / Keychain).
- [ ] Шифрование чувствительных данных.
- [ ] Защита от MITM: HTTPS, проверка сертификатов.
