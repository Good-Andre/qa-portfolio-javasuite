# 📱 Mobile Testing Case Study

Мини‑проект, демонстрирующий подход к тестированию мобильного приложения (Flutter) на Android и iOS. Акцент на специфику мобильных платформ: жизненный цикл, сенсорные взаимодействия, ориентация экрана, сеть и производительность.

## 📱 Специфика мобильного тестирования

- **Сенсорные взаимодействия:** тапы, свайпы, пинч, мультитач, длинные нажатия.
- **Жизненный цикл:** запуск, сворачивание, восстановление, kill процесса, push‑уведомления.
- **Ориентация и форм‑факторы:** портретная/альбомная, разные разрешения, планшеты.
- **Сеть:** офлайн, слабый сигнал, переключение Wi‑Fi/мобильный, потеря сети.
- **Ресурсы устройства:** память, CPU, батарея, хранение данных.
- **Доступность:** TalkBack/VoiceOver, размер текста, контрастность.

## 🚀 Быстрый старт

Вся документация — статические Markdown‑файлы. Для ознакомления:

```bash
cd mobile-testing && cat README.md
```

Автотесты описаны в `Automation_Plan.md`. Реальные тесты выполняются в рамках Flutter‑проекта:

```bash
flutter test test/mobile/           # unit/widget
flutter test integration_test/      # E2E
flutter drive                       # UI automation (если требуется)
```
