# 🧠 Mobile Test Strategy

## Цели тестирования

- Подтвердить корректную работу на Android и iOS (разные версии ОС, устройства).
- Проверить критичные пользовательские сценарии (регистрация, вход, основные действия).
- Выявить проблемы UX, связанные с мобильным форм‑фактором.
- Оценить стабильность при прерываниях (звонки, уведомления, сворачивание).
- Измерить производительность (FPS, потребление памяти, время запуска).

## Области тестирования

| Область | Фокус | Инструменты |
| :--- | :--- | :--- |
| **Функциональное** | Основные сценарии, граничные значения, валидация форм | Flutter Test, Integration Test |
| **UI/UX** | Адаптивность, читаемость, навигация, соответствие гайдлайнам | Manual, Playtests |
| **Сенсор** | Тапы, свайпы, мультитач, пинч | Manual, E2E |
| **Жизненный цикл** | Запуск, сворачивание, kill, восстановление | Manual, E2E |
| **Сеть** | Онлайн/офлайн, слабый сигнал, смена сети | Manual, Stubs |
| **Производительность** | FPS, память, время запуска, энергопотребление | DevTools, Instruments, Android Studio Profiler |
| **Доступность** | TalkBack, VoiceOver, масштабирование текста | Manual |
| **Безопасность** | Хранение токенов, шифрование, защита данных | Manual, SAST |

## Риски и приоритеты

| Риск | Вероятность | Влияние | Приоритет |
| :--- | :--- | :--- | :--- |
| Критичный баг в основном сценарии (вход/регистрация) | Высокая | Критическое | 🔴 Critical |
| Проблемы с адаптивностью на планшетах/нестандартных экранах | Средняя | Высокое | 🟡 High |
| Падение при сворачивании/восстановлении | Средняя | Высокое | 🟡 High |
| Высокий расход батареи при активном использовании | Низкая | Среднее | 🟢 Medium |
| Нечитаемые элементы при увеличении текста | Средняя | Среднее | 🟡 High |

## Критерии приёмки

- Все критические сценарии проходят без ошибок.
- Нет визуальных дефектов на основных устройствах (iPhone, Pixel, Samsung).
- Приложение не падает при сворачивании и восстановлении.
- Время запуска < 3 сек на среднем устройстве.
- FPS ≥ 45 при активных анимациях.
- Поддержка TalkBack/VoiceOver на ключевых экранах.
