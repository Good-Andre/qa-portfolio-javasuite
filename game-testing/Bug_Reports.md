# 🐞 Баг-репорты (Bug Reports)

Шаблон и примеры баг-репортов для пазл-игры на Flutter + Flame. Все репорты содержат аппаратные данные, шаги воспроизведения, ожидаемое/фактическое поведение и приоритет.

## 📋 Шаблон баг-репорта

- **ID:** BUG-XXXX (уникальный номер)
- **Заголовок:** Краткое описание проблемы (до 80 символов)
- **Приоритет (Priority):** Low / Medium / High / Critical / Blocker
- **Серьёзность (Severity):** Minor / Major / Critical / Blocking
- **Платформа:** Web (Chrome/Firefox) или Windows (конфигурация)
- **Графический движок:** Impeller / Skia (для Windows)
- **Версия сборки:** vX.Y.Z (или хэш коммита)
- **Аппаратные данные:** ОС, CPU, GPU, ОЗУ, разрешение экрана
- **Шаги воспроизведения (Steps to Reproduce):** Нумерованный список действий
- **Ожидаемое поведение (Expected Result):** Что должно происходить
- **Фактическое поведение (Actual Result):** Что происходит на самом деле
- **Скриншоты / Видео:** Ссылки на артефакты
- **Дополнительная информация:** Логи, стек трейса, особенности Flame-компонентов

## 🧪 Примеры баг-репортов

### BUG-001: Краш при быстром перетаскивании элементов

- **Заголовок:** Краш игры при быстром Drag & Drop (race condition в update())
- **Приоритет:** Critical
- **Серьёзность:** Blocking
- **Платформа:** Windows Desktop
- **Графический движок:** Impeller
- **Версия сборки:** v0.3.1 (commit abc123)
- **Аппаратные данные:** Windows 11, Intel Core i5-12400, Intel UHD Graphics, 16 ГБ ОЗУ, 1920×1080
- **Шаги воспроизведения:**
  1. Открыть уровень 3.
  2. Быстро перетаскивать элементы (более 5 раз в секунду).
  3. Одновременно отпускать и кликать по разным элементам.
- **Ожидаемое поведение:** Элементы корректно перемещаются, анимация отрабатывает, игра не падает.
- **Фактическое поведение:** Игра крашится через 10–15 секунд хаотичного инпута. В логах: исключение в `update()` из-за одновременного доступа к `Component` дереву.
- **Скриншоты / Видео:** [ссылка на видео]
- **Дополнительная информация:** Баг воспроизводится стабильно на Impeller, на Skia — реже. Связано с обработкой очереди событий в `Draggable`-миксине Flame.

### BUG-002: Потеря сохранения при сворачивании окна

- **Заголовок:** Потеря прогресса при сворачивании/разворачивании окна (Windows)
- **Приоритет:** High
- **Серьёзность:** Critical
- **Платформа:** Windows Desktop
- **Графический движок:** Skia
- **Версия сборки:** v0.3.1
- **Аппаратные данные:** Windows 10, NVIDIA RTX 3060, 16 ГБ ОЗУ, 2560×1440
- **Шаги воспроизведения:**
  1. Пройти уровень 2 (прогресс сохраняется).
  2. Свернуть окно (Win+D).
  3. Развернуть окно.
  4. Проверить статус уровней в меню.
- **Ожидаемое поведение:** Прогресс сохраняется, уровень 2 остаётся пройденным.
- **Фактическое поведение:** Уровень 2 отображается как непройденный, прогресс сброшен.
- **Скриншоты / Видео:** [скриншот меню до/после]
- **Дополнительная информация:** Проблема связана с обработкой `onVisibilityChanged` и асинхронной записью в `shared_preferences`. На Web баг не воспроизводится.

### BUG-003: Визуальные артефакты при наложении Overlay (Impeller)

- **Заголовок:** Артефакты прозрачности при отображении экрана победы (Overlay)
- **Приоритет:** Medium
- **Серьёзность:** Major
- **Платформа:** Windows Desktop
- **Графический движок:** Impeller
- **Версия сборки:** v0.3.1
- **Аппаратные данные:** Windows 11, AMD RX 6600, 16 ГБ ОЗУ, 3440×1440 (21:9)
- **Шаги воспроизведения:**
  1. Собрать пазл уровня 1.
  2. Дождаться появления экрана победы (Overlay).
  3. Обратить внимание на края полупрозрачного фона.
- **Ожидаемое поведение:** Полупрозрачный фон Overlay отображается без артефактов, края ровные, без «лесенки» или мерцания.
- **Фактическое поведение:** На краях полупрозрачного фона видны артефакты (полосы, мерцание), особенно на ультрашироком экране.
- **Скриншоты / Видео:** [скриншоты на 21:9]
- **Дополнительная информация:** На Skia артефактов нет. Вероятно, проблема с обработкой альфа-канала в Impeller.

### BUG-004: Некорректный подсчёт очков при отмене хода

- **Заголовок:** Неверный подсчёт очков после отмены хода (Undo)
- **Приоритет:** High
- **Серьёзность:** Major
- **Платформа:** Web (Chrome)
- **Графический движок:** CanvasKit
- **Версия сборки:** v0.3.1
- **Аппаратные данные:** Chrome 152, Windows 11, 1920×1080
- **Шаги воспроизведения:**
  1. Сделать 3 хода на уровне 1.
  2. Нажать «Отмена хода» (Undo).
  3. Завершить уровень.
- **Ожидаемое поведение:** Очки рассчитываются корректно с учётом отмены хода (штраф за ход не применяется).
- **Фактическое поведение:** Очки начисляются так, будто отмена не произошла — штраф за 3 хода всё равно применяется.
- **Скриншоты / Видео:** [лог расчёта очков]
- **Дополнительная информация:** Ошибка в логике пересчёта очков при изменении состояния стека ходов.
