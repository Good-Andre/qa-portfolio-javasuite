# 🎮 Game QA Case Study: Кроссплатформенная Пазл-Игра (Flutter + Flame)

QA-документация для тестирования кроссплатформенной пазл-игры, разрабатываемой на Flutter с игровым движком Flame.

## 🕹 Описание игры (High Concept)

Пространственный пазл: игрок перемещает и вращает элементы на игровом поле для достижения целевого состояния. Система уровней с нарастающей сложностью, ограничение по ходам и подсчёт очков по итогам прохождения.

- **Движок:** Flutter 3.x + Flame Engine
- **Графические бекенды:** Impeller (основной) и Skia (для сравнительного тестирования)
- **Платформы:** Web (Flutter Web, CanvasKit) и Windows Desktop (standalone .exe)
- **Стадия:** Рабочий прототип с готовой ключевой механикой

## 🎯 Специфика Game QA для данного проекта

В отличие от классического веб-тестирования, фокус смещён на:

1. **Игровой цикл (Core Gameplay Loop).** Безбаговость механики перемещения, обработка коллизий, триггеры победы и поражения, корректность начисления очков.
2. **Кроссплатформенность.** Разница инпута (мышь / тач / трекпад), масштабирование графики, рендеринг через CanvasKit (Web) и Impeller / Skia (Windows).
3. **Сравнение графических движков (Impeller vs Skia).** Оценка стабильности FPS, времени отрисовки кадров, потребления памяти и визуальных артефактов на обоих бекендах.
4. **Состояние игры (State Management).** Сохранение прогресса, обработка прерываний: пауза, сворачивание окна, потеря фокуса вкладки.
5. **Производительность.** Стабильность FPS, отсутствие утечек памяти при длительных сессиях, время загрузки уровней.

## 🔗 Связь с автоматизацией

Ручные кейсы из этого раздела дополняют автоматизированные тесты внутри Flutter-проекта:

- **Widget-тесты** (`flutter test`): проверка логики игровых компонентов в изоляции.
- **Golden-тесты** (`matchesGoldenFile`): визуальная регрессия UI-элементов и анимаций.
- **Интеграционные тесты** (`integration_test`): сквозные сценарии игрового цикла.

Часть проверок (UX, баланс, адаптивность, плейтесты) остаётся ручной — низкий ROI автоматизации и необходимость человеческой оценки.
