# 🖥 Матрица кроссплатформенного тестирования: Web vs Windows

Матрица проверок специфики Flutter Web (CanvasKit) и Windows Desktop (Impeller / Skia). Документ включает отдельный раздел по сравнению графических движков.

---

## 1. Сравнение специфики платформ

| Область проверки | Специфика Web (Flutter Web, CanvasKit) | Специфика Windows Desktop (.exe) |
| :--- | :--- | :--- |
| **Управление (Input)** | Проверка Touch-событий (симуляция мобильных устройств в Chrome DevTools) и кликов мыши. Flame `HasTappables` / `Draggable` — корректность координат при масштабировании CanvasKit. | Проверка корректности работы мыши, трекпада и горячих клавиш (ESC — пауза, Space — сброс). Проверка `RawKeyDownEvent` / `RawKeyUpEvent` в Flame. |
| **Разрешение экрана** | Изменение размера окна браузера (Responsive / Scaling). Игра должна адаптировать UI под любое соотношение сторон (16:9, 21:9, 4:3). Проверка `LayoutBuilder` / `MediaQuery`. | Переключение между оконным режимом и Fullscreen (Alt+Enter). Разрешение UI не должно «плыть» при смене разрешения монитора. |
| **Производительность** | Замер FPS и утечек памяти через вкладку Performance в Chrome DevTools при длительной сессии (30+ минут). Мониторинг `window.flutter_rendered_frames`. | Мониторинг потребления ресурсов CPU и GPU через Диспетчер задач и Dart DevTools PerformanceOverlay. Игра не должна «течь» — проверка удаления Flame `Component` из дерева. |
| **Фокус приложения** | Переключение на другую вкладку браузера — игра должна автоматически встать на паузу или заглушить звук (`VisibilityDetector` / `document.visibilityState`). | Сворачивание игры (Win+D или Alt+Tab). При разворачивании игра не должна крашиться, терять текстуры или показывать чёрный экран. |
| **Кэш и сохранения** | Очистка кэша браузера — проверка поведения игры после удаления сохранений из LocalStorage / IndexedDB. | Проверка создания файлов сохранений в папке `AppData/Local/` или корне игры. Проверка прав на запись. |
| **Звук** | Проверка `audioplayers` / `flame_audio` в браузере — автозапуск звука блокируется браузером до первого пользовательского взаимодействия. | Проверка аудио без ограничений браузера. Корректное переключение аудиоустройств при сворачивании / разворачивании. |
| **Шрифты и текст** | CanvasKit рендерит шрифты через собственный движок — проверка кириллицы, межстрочного интервала, переноса строк. | Проверка системных шрифтов и fallback при отсутствии кастомного шрифта. |
| **Контекстное меню** | Правый клик в браузере вызывает контекстное меню браузера — игра должна перехватывать или игнорировать его в игровом поле. | Правый клик не вызывает системных меню вне контекста игры. |

## 3. Чек-лист переключения рендереров

- [ ] Запуск с `--enable-impeller` — игра корректно стартует, артефактов нет
- [ ] Запуск с `--no-enable-impeller` (Skia) — игра корректно стартует, артефактов нет
- [ ] Переключение бекенда не влияет на логику игры (геймплей идентичен)
- [ ] Переключение бекенда не влияет на сохранения
- [ ] Golden-тесты проходят на обоих бекендах (если применимо)
